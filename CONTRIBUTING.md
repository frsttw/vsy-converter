# Contributing

Vsy Converter is maintained as a personal portfolio project by [frsttw](https://github.com/frsttw).

Project-facing text must be written in English: application labels, documentation, screenshots, release notes, commit messages, and installer text. Keep changes focused, preserve the original-file safety guarantees, and run the automated test suite before packaging a release.

```powershell
py -m unittest discover -q
```
