Vsy Converter

1. Open "Vsy Converter" from the Windows Start menu.
2. Click "+ Add" and choose images or videos (videos produce GIF files).
3. Select the output format and adjust quality or size if needed.
4. Choose the destination folder.
5. Click "Convert files".

The app never overwrites original files. If a file with the same name already
exists, it creates a numbered copy.

In the Discord tab, choose an image or GIF and select Avatar or Profile banner.
Each destination folder is remembered. AUTO keeps animation; PNG/JPG save only
the first frame. The app validates dimensions and file size before saving.

GIFs are processed by FFmpeg with frame progress during encoding. Color analysis
and compression attempts can take longer for large GIFs. If the result exceeds
the target, the app explains why without changing your original.

Use Cancel to stop a task. Actions remain available in smaller windows.
ImageMagick and FFmpeg are included in the installer.

In the Cuts tab, choose a video, audio file, or GIF, enter the start and end,
and press "Cut media". Video and audio use direct stream copy without
recompression; GIFs are re-encoded to remove frames while preserving resolution
and animation. Use seconds or HH:MM:SS.000. Leave the end empty to cut to the end.
